# Example Skill: Getting Started with {{name}}

This is an example skill file. Skills are optional complementary prompts and guides
that help users work with your toolkit.

## What Are Skills?

Skills are markdown files containing:
- Step-by-step guides
- Helpful prompts for common tasks
- Best practices and tips
- Troubleshooting advice

## How to Use

Users can copy skills to their coding agent's skills folder after installing
your toolkit:

```bash
cp ~/.scitoolkit/toolkits/{{name}}/skills/* ~/my-project/skills/
```

## Example Skill Content

Here's a helpful prompt for using this toolkit:

**Task:** Analyze data using {{name}}

**Steps:**
1. Load your data using the appropriate tool
2. Process it with the analysis tools
3. Visualize or export results

**Tips:**
- Always validate your input data first
- Use descriptive names for output files
- Check the README for advanced options
- Review tool docstrings for parameter details
